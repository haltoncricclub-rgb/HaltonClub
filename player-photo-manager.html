One-time setup: connect to GitHub

This lets the tool save photos straight to your site — no downloading files or visiting GitHub yourself. You only need to do this once; your phone will remember it.

How do I get a token? (one-time, ~2 minutes)
  1. On your phone or computer, go to github.com/settings/personal-access-tokens/new (you'll need to be logged into the haltoncricclub-rgb account)
  2. Token name: anything, e.g. "Photo Uploader"
  3. Expiration: pick whatever you're comfortable with (e.g. 1 year — you can always make a new one later)
  4. Repository access: choose "Only select repositories" → pick HaltonClub
  5. Permissions → Repository permissions → find "Contents" → set to Read and write (leave everything else as "No access")
  6. Scroll down, click Generate token
  7. Copy the token (starts with github_pat_) and paste it above

This token can only read/write files in this one repo — nothing else on your GitHub account, even if your phone were lost.

    How to finish

    With direct upload ON (recommended on phone): nothing else to do — each photo you add is already live on the site. Give it a minute or two, then check the site.

    With direct upload OFF (or no token saved):

    1. Download all the photos (step 4 above)
    2. In your GitHub repo, go to the data folder — if there's no photos folder yet, create one the same way you create any new file (type photos/ at the start of a new filename and GitHub creates the folder)
    3. Upload all the downloaded photo files into data/photos/
    4. Open data/player-photos.json in your repo (create it if it doesn't exist yet, starting from {}) and merge in the JSON from step 5 above
    5. Commit and push, same as always
